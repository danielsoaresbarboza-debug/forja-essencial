# Forja.Treino

App de treino, dieta, água e evolução (PWA). Abre no navegador e instala na tela inicial.

- Os dados ficam no aparelho de cada pessoa (e, se ela quiser, numa planilha no Google Drive dela).
- Este repositório tem só o código do app. Nunca colocar aqui backups, exames, senhas ou chaves.
